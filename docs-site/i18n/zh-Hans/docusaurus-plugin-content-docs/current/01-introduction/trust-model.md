Custos 运行在操作者自有基础设施上。交易所凭据在本地加密，由本地交易客户端使用。runner 遥测不会将交易所秘密或签名私钥发送给 ARX。

## 签名操作

ARX 认证用户、授权意图并管理正式部署决策。Custos 验证签发的目标状态、解析本地凭据、执行部署并签名观测。runner 不能批准自己的正式部署或晋升。

指令验证覆盖精确字节和 subject，事实验证覆盖注册公钥、范围和序号。Custos 不提供 HTTP 管理端点，但经 broker 到达的输入仍需认证和校验。

## 离线操作

操作者可显式选择独立的 sandbox/testnet 通道，生成未认证身份并发布本地目标状态。该路径信任操作者控制的基础设施和挂载策略代码。状态未签名，不能运行 live，也不产生晋升证据。它不是签名验证失败后的兜底路径。

## 本地安全与可用性

上游暂时不可用本身不会停止已应用的部署，本地安全检查独立继续。凭据过期、撤销、引擎故障和无效授权是不同条件，可能停止执行。离线与签名策略范围不同，详见[断线时的安全控制](/trust-model/safety-survives-disconnect)。

## 核查边界

Apache-2.0 源码、契约资产和测试支持独立检查。源码审查不能证明已部署行为，应验证实际使用的精确产物和配置。宿主访问控制、交易所权限和策略风险仍由操作者负责。

实现和验证范围见[四项保障](/trust-model/red-lines)、[架构](/introduction/architecture-at-a-glance)与[审计清单](/trust-model/audit-checklist)。
