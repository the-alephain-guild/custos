Custos 使用 Apache-2.0 许可证，正式文本见仓库中的[LICENSE](https://github.com/the-alephain-guild/custos/blob/main/LICENSE)和[NOTICE](https://github.com/the-alephain-guild/custos/blob/main/NOTICE)。

许可证允许按其条款使用、修改和再分发，包括商业用途。应保留必要声明，并按许可证要求标明修改。专利授权及其他条件以许可证正文为准。

项目不要求单独签署 CLA，开发流程见[参与贡献](/release-governance/contributing)。第三方组件保留各自许可证及归属信息；再分发时应核查 NOTICE 和相应包材料。
