[CHANGELOG.md](https://github.com/the-alephain-guild/custos/blob/main/CHANGELOG.md) records package changes. Check the Git revision and release artifact alongside an entry: a dated changelog section alone does not establish publication or deployed acceptance.

The checkout declares runner version `0.3.0`. Candidate toolkit and runtime-image records are tracked separately in [release status](/release-governance/release-status).

For changes after the last changelog entry, inspect the repository history and the relevant [upgrade guidance](/release-governance/upgrade-paths), including Nautilus 2, standalone identity, offline deployment and venue support. Review `Changed`, `Removed` and `Deprecated` sections before upgrading. Compatibility and support commitments remain in [SemVer and LTS](/release-governance/semver-lts).
